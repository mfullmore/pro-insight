# pro-insight

Turns a department budget `.xlsx` into an interactive, editable web page — anyone can open it, tweak numbers, and see formulas recalculate live, without needing Excel or any spreadsheet software.

This repo holds **four parallel implementations** of that idea, each built for a different place teams actually work. They share the same core conversion and rendering logic (`browser-converter/core/convert-core.js` and `render-core.js`), vendored into the other three.

## The four options

| Option | Directory | What it is |
|---|---|---|
| **Browser Converter** | [`browser-converter/`](browser-converter) | A single self-contained HTML page. Drag in an `.xlsx`, download a self-contained interactive HTML file. No install, no server, no account. |
| **Excel Add-in** | [`office-addin/`](office-addin) | Adds an **Export as Interactive Plan** button to Excel's ribbon. Reads the open workbook directly via Excel's JS API and downloads the interactive page. |
| **Confluence App** | [`confluence-forge-app/`](confluence-forge-app) | A Forge Custom UI macro. Reads an `.xlsx` already attached to a Confluence page, renders it in place, and saves edits back as a new attachment version. |
| **SharePoint Web Part** | [`sharepoint-webpart/`](sharepoint-webpart) | An SPFx web part. Reads an `.xlsx` from a document library, renders it on the page, and saves edits back as a new file version. |

All four are fully tested against real environments. See [`options-comparison.html`](options-comparison.html) for a detailed side-by-side comparison, and each option's own `support/README.md` for setup instructions and real issues/fixes encountered during testing.

## Getting started

Each option lives in its own directory with its own `package.json`. Pick one, then:

```bash
cd <option-directory>
npm install
```

From there, follow that option's `support/README.md` for build/run/deploy steps specific to its platform (static file, Office Add-in sideload, Forge deploy, or SPFx package-and-upload).

## Repo layout

- `browser-converter/core/` — shared conversion (`convert-core.js`) and rendering (`render-core.js`) logic used by all four options
- `<option>/fixtures/` — sample budget workbooks used for testing that option
- `<option>/support/README.md` — setup guide plus a real-world troubleshooting log for that option
- `enterprise-budget-fy26.xlsx` — sample workbook, generated by `support/generate-enterprise-budget.js`
- `options-comparison.html` — full comparison of all four options
